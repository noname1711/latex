| Action | Keyboard Shortcut |
|---|---|
| Build LaTeX manually | `Ctrl+Alt+B` |
| Open PDF Preview | `Ctrl+Alt+V` |
| Sync from LaTeX source to PDF | `Ctrl+Alt+J` |
| Sync from PDF to LaTeX source | `Ctrl+Click` on PDF |
| Select a different LaTeX compiler | `Ctrl+Shift+P` → `LaTeX Workshop: Build with recipe` |

When using VSCode, add .vscode/settings.json
